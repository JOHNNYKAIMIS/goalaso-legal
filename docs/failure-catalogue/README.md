# Κατάλογος κλάσεων αστοχίας — goalaso-legal

Ένα σφάλμα διορθώνεται μία φορά. Μια **κλάση** σφαλμάτων ξαναγυρίζει μέχρι να υπάρξει μηχανισμός
που την πιάνει. Ένα αρχείο ανά κλάση, όχι ανά bug.

**Κανόνες:**
1. Κλάση χωρίς φύλακα (`guard-script` που υπάρχει και τρέχει) είναι **ΑΝΟΙΧΤΗ**, ακόμα κι αν ο
   κώδικας διορθώθηκε. Η διόρθωση λέει «δεν συμβαίνει τώρα»· μόνο ο φύλακας λέει «δεν μπορεί να
   ξανασυμβεί».
2. Το STATUS **παράγεται** τρέχοντας τους φύλακες — ποτέ δεν γράφεται με το χέρι. Δεν υπάρχει
   ακόμα STATUS.md εδώ, επειδή δεν υπάρχει ακόμα κανένας φύλακας: όλες οι κλάσεις είναι
   ΑΝΟΙΧΤΕΣ εξ ορισμού (`ls docs/failure-catalogue/G*.md` = οι κλάσεις · κανένα `guard-script`
   δεν υπάρχει ακόμα στο repo). Ο πρώτος γύρος του βρόχου («επόμενο») φέρνει τον πρώτο φύλακα
   ΚΑΙ τον generator του STATUS μαζί.
3. Κλειστές κλάσεις δεν διαγράφονται — είναι η δικαιολογία ύπαρξης του φύλακά τους.

# Κατάλογος κλάσεων αστοχίας — goalaso-legal

Ένα σφάλμα διορθώνεται μία φορά. Μια **κλάση** σφαλμάτων ξαναγυρίζει μέχρι να υπάρξει μηχανισμός
που την πιάνει. Ένα αρχείο ανά κλάση, όχι ανά bug.

**Κανόνες:**
1. Κλάση χωρίς φύλακα (`guard` που υπάρχει και τρέχει) είναι **ΑΝΟΙΧΤΗ**, ακόμα κι αν ο
   κώδικας διορθώθηκε. Η διόρθωση λέει «δεν συμβαίνει τώρα»· μόνο ο φύλακας λέει «δεν μπορεί να
   ξανασυμβεί». Φύλακας χωρίς απόδειξη (`prove`) είναι ισχυρισμός, όχι μηχανισμός.
2. Η κατάσταση **παράγεται** τρέχοντας τους φύλακες — ποτέ δεν γράφεται με το χέρι:
   [STATUS.md](STATUS.md) βγαίνει από `node scripts/catalogue-status.mjs`, που τρέχει τον
   φύλακα ΚΑΙ την απόδειξη κάθε κλάσης. Το CI τρέχει `--check` και κοκκινίζει αν το αρχείο
   δεν ταιριάζει με ό,τι παράγουν οι φύλακες. Κάθε κλάση δηλώνει στην κεφαλίδα της
   (`<!--catalogue … -->`) `kind: open | guarded` και, αν είναι guarded, `guard:` + `prove:`.
3. Κλειστές κλάσεις δεν διαγράφονται — είναι η δικαιολογία ύπαρξης του φύλακά τους.

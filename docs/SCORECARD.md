## Τι είναι αυτό το repo (χαρτογράφηση 2026-08-21)

Τρεις στατικές σελίδες HTML — `index`, `privacy`, `terms` (`wc -l *.html` → μετρήθηκε 192 γραμμές
συνολικά στις 2026-08-21) — οι νομικές σελίδες της εφαρμογής Goalaso (οργάνωση ερασιτεχνικού
futsal). Δίγλωσσες (ελληνικά + αγγλικά στο ίδιο αρχείο). Μέχρι τον γύρο 1: κανένα build, κανένα
test, κανένα CI (`ls -A .github 2>/dev/null` → τίποτα στις 2026-08-21). Ό,τι γίνεται push βγαίνει
όπως είναι. Από τον γύρο 1 (2026-08-22): `.github/workflows/quality.yml` σε κάθε push + PR,
`npm run check` τοπικά, χωρίς εξαρτήσεις (`cat package.json` → `scripts` μόνο).

**Πώς βγαίνει (μετρήθηκε 2026-08-22):** GitHub Pages με source `main` `/`, legacy build
(`gh api repos/JOHNNYKAIMIS/goalaso-legal/pages --jq '.source,.build_type'`). Μέχρι τον γύρο 1 το
ΜΟΝΟ που έτρεχε σε push ήταν το dynamic `pages-build-deployment`
(`gh api repos/JOHNNYKAIMIS/goalaso-legal/actions/workflows --jq '.workflows[].path'` → μόνο
`dynamic/pages/pages-build-deployment`) — deploy, όχι έλεγχος. Δηλαδή **push στο main =
δημοσίευση μέσα σε δευτερόλεπτα** (push 16:23:26Z → run 16:23:31Z), χωρίς branch protection
(`gh api repos/JOHNNYKAIMIS/goalaso-legal/branches/main/protection` → 404). Το
`goalaso.net/privacy.html` ΔΕΝ είναι αυτό το repo: επιστρέφει το SPA της εφαρμογής
(`curl -s https://goalaso.net/privacy.html | grep -o '<title>[^<]*'` → «Goalaso — Όλα για την
μπάλα.»). Ο σύνδεσμος που βλέπουν χρήστες και stores είναι το github.io (app repo:
`grep -rn goalaso-legal apps/mobile/src/utils/support.ts docs/marketing/play-console-paste-sheet.md`).

**Ποιος τις διαβάζει:** οι χρήστες της εφαρμογής (link από τα stores/app) και —το σημαντικότερο—
όποιος ασκήσει δικαίωμα GDPR ή υποβάλει καταγγελία στην Επίτροπο Κύπρου.

**Το χειρότερο πιθανό σφάλμα:** η πολιτική να υπόσχεται κάτι που η εφαρμογή δεν κάνει (ή το
αντίστροφο). Δεν είναι υπόθεση — συνέβη: το ιστορικό (`git log --oneline`) δείχνει ότι η
πολιτική περιέγραφε διαγραφή «μόνο μέσω email» ενώ η εφαρμογή απέκτησε in-app διαγραφή, και
διορθώθηκε με το χέρι όταν το πρόσεξε κάποιος (commit `30421cc`, 2026-08-03).

**Τι το εμποδίζει σήμερα:** από τον γύρο 1, ο φύλακας της κλάσης G04 σε κάθε push/PR — δομή
HTML, εσωτερικά links, κωδικοποίηση (`node scripts/html-check.mjs`). Για το χειρότερο σφάλμα
(G01), τη δίγλωσση απόκλιση (G02) και την ημερομηνία (G03): ακόμα τίποτα
(`node scripts/catalogue-status.mjs` → [STATUS.md](failure-catalogue/STATUS.md)).
